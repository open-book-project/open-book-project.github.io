    About this book¶

    A first course in data science with Python for readers who know school mathematics and a little programming. It follows the whole workflow: asking a question, NumPy arrays, loading, cleaning, reshaping, grouping and joining tables with pandas, exploratory analysis and plots with matplotlib, probability and statistical inference, regression, classification, model evaluation and cross-validation, clustering and dimensionality reduction, text and time series, and ethics, privacy and reproducibility, ending with a complete project. Every dataset is made in code and every program has been run, with its real output shown.
