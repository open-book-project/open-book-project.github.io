    Glossary and Further Reading¶

    Glossary¶

    ABI (application binary interface)
    The convention that gives each register a role and says which registers a called function must preserve, so that code written by different people works together. A convention, not hardware.
    Active low
    A signal that does its job when it is 0. By convention its name ends in _n, as in rst_n.
    ALU (arithmetic logic unit)
    The combinational block that performs the arithmetic and logic microoperations; in a processor it also computes memory addresses and compares values for branches.
    Architecture (VHDL)
    The inside of a design unit: the concurrent statements and processes that implement an entity.
    Assertion
    A VHDL statement (assert ... report ... severity) that checks a condition during simulation and reports when it is false.
    Asynchronous reset
    A reset that acts the instant it is asserted, without waiting for a clock edge. In Verilog and VHDL it appears in the sensitivity list of the clocked process.
    Behavioural description
    A description of what a circuit does, without saying how it is built; also the style of coding in an always block or a process, from which synthesis works out the gates.
    Blocking assignment
    The Verilog assignment =, which takes effect immediately and in order. Used for combinational logic.
    Branch prediction
    A guess, made by a pipeline, of the outcome of a branch before it is decided, so that fetching can go on; wrongly fetched instructions are discarded.
    Bus
    One set of shared wires carrying the value of exactly one chosen register at a time.
    Callee-saved register
    A register (s0–s11, sp in RISC-V) that a function must leave unchanged when it returns, saving and restoring it if it uses it.
    Caller-saved register
    A register (t0–t6, a0–a7, ra) that a called function may overwrite; the caller must save it first if it needs the value afterwards.
    Clock edge
    The instant at which the clock changes, usually 0 to 1 (the rising edge). Registers load only at clock edges.
    Combinational logic
    Logic whose outputs depend only on the present inputs, with no memory.
    Concatenation
    Joining bits side by side into a wider vector: {a, b} in Verilog, a & b in VHDL. It builds no logic, only wiring.
    Control function
    The Boolean condition before the colon in a conditional transfer, such as P in P: R2 ← R1.
    Control unit
    The finite state machine that asserts the control signals of the datapath in the right order.
    Datapath
    The registers, ALU, shifters, buses and multiplexers where data is held and transformed.
    DUT (device under test)
    The design that a testbench instantiates and drives.
    Entity (VHDL)
    The interface of a design unit: its name and its ports.
    Enumerated type
    A VHDL type whose values are names, used for the states of a state machine.
    Finite state machine (FSM)
    A circuit that is always in one of a finite number of states and moves between them on clock edges. The control unit of an RTL design is an FSM.
    Forwarding
    Sending a result directly from a pipeline stage to the ALU input of a later instruction, without waiting for it to be written to the register file.
    funct3, funct7
    Fields of a RISC-V instruction that, together with the opcode, select the operation.
    Generate
    A construct (Verilog generate, VHDL for ... generate) that builds repeated structure while the design is being elaborated.
    Generic / parameter
    A constant chosen when a design is instantiated, such as a bit width: generic in VHDL, parameter in Verilog.
    Hardwired control
    A control unit built from gates and a state register, fast but fixed.
    Hazard
    A situation in a pipeline in which the next instruction cannot safely go ahead in its cycle: a data hazard, or a control hazard.
    High impedance (Z)
    The state of an output that is not driving its wire at all.
    Immediate
    A constant held in the instruction itself. In RISC-V it is sign-extended to 32 bits.
    Instruction set architecture (ISA)
    The specification of the instructions a processor understands, its registers, its memory addressing and the encoding of the instructions.
    Latch
    A level-sensitive storage element. In a hardware description it is usually an accident, caused by a combinational block that does not assign an output on every path.
    Leaf function
    A function that calls no other function, and so need not save ra.
    Load-store architecture
    An architecture in which only load and store instructions access memory, and arithmetic works on registers alone.
    Mealy machine
    A state machine whose outputs depend on the state and on the inputs.
    Microoperation
    An elementary operation on register contents, completed in one clock pulse.
    Microprogrammed control
    A control unit that reads its control signals from a small memory, one word per step. Flexible, but slower.
    Module
    The building block of Verilog: a name, ports and a body.
    Moore machine
    A state machine whose outputs depend on the state only.
    Non-blocking assignment
    The Verilog assignment <=, which reads all right-hand sides first and updates all left-hand sides together at the end of the time step. Used for clocked logic; the counterpart of the RTL arrow.
    numeric_std
    The IEEE VHDL package that defines unsigned and signed vectors and their arithmetic and conversions.
    Opcode
    The low 7 bits of a RISC-V instruction, which identify its format and class.
    Pipeline
    A datapath divided into stages so that several instructions are in progress at once.
    Process (VHDL)
    A concurrent statement that contains sequential statements, used for combinational and clocked logic.
    Pseudo-instruction
    An assembler shorthand, such as li, mv, nop, j or ret, that expands to one or more real instructions.
    Register
    A group of flip-flops that holds a multi-bit value until it is told to load a new one.
    Register file
    The array of registers of a processor, with read ports and a write port.
    Register transfer level (RTL)
    The level of description of a synchronous circuit as data moving between registers under a clock, with operations and control.
    RISC and CISC
    Reduced and complex instruction set computers: few, simple, regular instructions against many powerful instructions of varying length.
    Sensitivity list
    The signals whose changes make an always block or a process run again.
    Sign extension
    Copying the top bit of a narrow signed value leftwards to fill a wider one, which preserves its value.
    Signal (VHDL)
    A wire or register between blocks, updated when the process that assigns it suspends.
    Stack
    A region of memory used to save values across function calls; in RISC-V it grows downwards and sp points at its top.
    std_logic
    The IEEE nine-valued VHDL logic type, which models drivers, high impedance and unknowns.
    Synthesis
    Turning a hardware description into a netlist of gates and flip-flops.
    Testbench
    A design unit with no ports that drives a design under test and checks its outputs. Never synthesised.
    Trace table
    A table with a row per step and a column per register of interest, used to predict and check the behaviour of a program or circuit.
    Tri-state
    An output that can be driven to 0, to 1 or left undriven (high impedance), so that several drivers can share a bus.
    Variable (VHDL)
    Local storage inside a process, updated immediately.
    wire and reg (Verilog)
    A wire is driven continuously; a reg is assigned in a procedural block. A reg is not necessarily a register.
    x (unknown)
    A Verilog logic value meaning unknown: an unset register, or two drivers in conflict.
    x0 (RISC-V)
    The register that is hard-wired to zero: reads give 0 and writes are ignored.

    Further reading¶

    The following are the standards and the standard texts on which a reader can build. They are listed by title so that you can find the current edition.

    Standards and specifications

    • IEEE Standard for Verilog Hardware Description Language (IEEE 1364), and IEEE Standard for SystemVerilog (IEEE 1800), which includes it.
    • IEEE Standard for VHDL Language Reference Manual (IEEE 1076), with its companion packages std_logic_1164 and numeric_std.
    • The RISC-V Instruction Set Manual, Volume I: Unprivileged ISA, published by RISC-V International. It defines RV32I, the extensions and the instruction encodings used in Chapters 8 to 10.

    Books

    • M. Morris Mano, Computer System Architecture and Digital Design. The register-transfer notation used in Chapters 1 and 2 is the notation of these texts.
    • David A. Patterson and John L. Hennessy, Computer Organization and Design: The Hardware/Software Interface, RISC-V edition. The source of the single-cycle datapath and the five-stage pipeline of Chapter 10, with much more on hazards.
    • Sarah L. Harris and David Harris, Digital Design and Computer Architecture, which develops digital design in both Verilog and VHDL and ends with a processor.

    Free tools

    • Icarus Verilog (iverilog, vvp) and Verilator, for simulating Verilog; GTKWave, for viewing waveforms; GHDL, for simulating VHDL.
    • Yosys, an open-source synthesis tool that shows what hardware a description produces.
    • EDA Playground, a browser-based environment that runs Icarus Verilog and GHDL with nothing to install.

    Where to go next

    With a correct RTL description in hand, two directions open. One turns the instruction set into a fast core, with pipelining, out-of-order execution, caches, on-chip interconnect and the interfaces (UART, SPI, I²C) that connect a processor to the world; the first sibling book in this collection follows it. The other follows the description through synthesis, floorplanning, placement, clock-tree synthesis, routing and timing signoff until it becomes a layout ready for manufacture; the second sibling book follows that.
