    Preface¶

    This book grew out of a frustration I encountered repeatedly: existing resources on cryptography and cybersecurity either stay comfortably abstract or dive into a single topic without connecting it to the broader ecosystem. A practitioner building a secure system needs both — the mathematical foundations that tell you why a primitive is secure, and the adversarial perspective that tells you how it breaks in the real world.

    Security Systems Engineering: From Cryptographic Primitives to Emerging Cyber Threats is my attempt to bridge that gap. It covers the full spectrum of the field — from the number theory underlying RSA to the eBPF syscall interception that powers runtime security in Kubernetes. Every chapter is written with the same goal: give you enough depth to reason about the problem yourself, not just recognise the answer.

    The book is designed for practitioners, researchers, and advanced students who require both theoretical depth and practical applicability. If you’re preparing for a career in security engineering, red teaming, or cryptographic system design, this is the reference I wish I’d had.

    The text is organized into ten major parts, each corresponding to a domain of security expertise:

    1. Foundations of Cryptography — Mathematical prerequisites, symmetric and asymmetric cryptography, hash functions, and key management.

    2. Network Security — Protocol vulnerabilities, firewalls, intrusion detection, and network architecture.

    3. Web Application Security — OWASP vulnerabilities, authentication mechanisms, API security, and secure development.

    4. Hardware Security — Side-channel attacks, fault injection, TPM, PUFs, and TEMPEST.

    5. Secure Communications — TLS, SSH, email security, VoIP, and network protocols.

    6. Malware Analysis — Dynamic and static analysis, reverse engineering, and countermeasures.

    7. Digital Forensics — Disk, memory, network, mobile, and cloud forensics.

    8. Vulnerability Research — Fuzzing, binary analysis, exploit development, and responsible disclosure.

    9. Security Architecture — Enterprise architecture, cloud-native security, and secure SDLC.

    10. Human Factor and Emerging Threats — Social engineering, phishing, AI security, IoT, quantum migration, and Web3.

    Each chapter includes worked examples, attack scenarios with mitigations, and exercises for self-assessment. Reference implementations are provided in Python, C, Solidity, and shell scripts throughout.

    Prerequisites: Readers should have familiarity with discrete mathematics (modular arithmetic, probability), computer architecture, operating systems, and basic networking.
