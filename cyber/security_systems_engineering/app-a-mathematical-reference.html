    Appendix A: Mathematical Reference¶

    This appendix provides a quick-reference for mathematical notation, identities, and algorithms used throughout the text.

    A.1 Number Theory Quick Reference¶

    Identity / Property Statement
    Euler’s Theorem \(a^{\phi(n)} \equiv 1 \pmod{n}\) if \(\gcd(a,n) = 1\)
    Fermat’s Little Theorem \(a^{p-1} \equiv 1 \pmod{p}\) if prime \(p \nmid a\)
    Wilson’s Theorem \((p-1)! \equiv -1 \pmod{p}\) for prime \(p\)
    Euler Totient \(\phi(pq) = (p-1)(q-1)\); \(\phi(p^k) = p^{k-1}(p-1)\)
    Carmichael Function \(\lambda(n) = \text{lcm}(p_1^{a_1-1}(p_1-1), …)\)
    CRT Unique \(x \bmod \prod n_i\) from \(x \equiv a_i \pmod{n_i}\)

    A.3 Group Theory Reference¶

    Group Operation Order
    \(\mathbb{Z}_n\) Addition mod \(n\) \(n\)
    \(\mathbb{Z}_n^*\) Multiplication mod \(n\) \(\phi(n)\)
    \(\mathbb{Z}_p^*\) (prime \(p\)) Multiplication \(p-1\)
    \(E(\mathbb{F}_p)\) Point addition \(\approx p\) (Hasse’s theorem)
    \((\{0,1\}^n, \oplus)\) XOR \(2^n\)

    A.4 Information Theory¶

    \[\begin{align*} H(X) &= -\sum_x p(x) \log_2 p(x) \quad \text{(Shannon entropy, bits)} \\ H_\infty(X) &= -\log_2 \max_x p(x) \quad \text{(min-entropy)} \\ H(X|Y) &= H(X,Y) - H(Y) \quad \text{(conditional entropy)} \\ I(X;Y) &= H(X) - H(X|Y) \quad \text{(mutual information)} \end{align*}\]

    Entropy of common password policies:

    Character Set Length Entropy
    Digits \(\{0\)-\(9\}\) 4 \(4 \log_2 10 \approx 13.3\) bits
    Lowercase 8 \(8 \log_2 26 \approx 37.6\) bits
    Alphanumeric 12 \(12 \log_2 62 \approx 71.4\) bits
    All printable ASCII (95) 16 \(16 \log_2 95 \approx 105.1\) bits
    BIP-39 word list (\(2^{11}\)) 12 words 132 bits

    A.5 Complexity Classes¶

    Class Description Example
    P Polynomial time (classical) AES encryption
    NP Non-deterministic polynomial SAT, Graph Coloring
    BQP Bounded-error quantum polynomial Factoring (Shor)
    NP-hard At least as hard as NP RSA factoring (believed)
    \(\mathsf{negl}(\lambda)\) Negligible function PRF advantage
