    Glossary¶

    Terms¶

    A quick reference to the technical terms used in the book.

    APT (Advanced Persistent Threat)
    A sophisticated, long-duration cyberattack — typically by a nation-state — focused on stealthily maintaining access to a target for months or years to steal data or conduct espionage.
    ARP Poisoning
    Sending false ARP (Address Resolution Protocol) messages to associate the attacker's MAC address with a legitimate IP, causing traffic to be redirected through the attacker.
    Authentication
    The process of verifying the identity of a user, device, or system before granting access. Passwords, PINs, biometrics, and hardware tokens are all forms of authentication.
    Botnet
    A network of malware-infected computers ("bots") controlled remotely by an attacker's Command-and-Control server, often without the owners' knowledge.
    Brute Force
    Systematically attempting every possible password or key combination until the correct one is found.
    Buffer Overflow
    Writing more data to a memory buffer than it can hold, causing the overflow to overwrite adjacent memory and potentially redirect program execution to attacker-controlled code.
    C2 / C&C (Command and Control)
    The infrastructure (server, domain, or channel) used by an attacker to remotely control malware or compromised systems in a botnet.
    CSRF (Cross-Site Request Forgery)
    An attack that tricks an authenticated user's browser into making unauthorised requests to a trusted site the user is already logged into.
    CVE (Common Vulnerabilities and Exposures)
    A standardised identifier for publicly disclosed cybersecurity vulnerabilities. Example: CVE-2021-4034 is the PwnKit Linux privilege escalation vulnerability.
    DDoS (Distributed Denial of Service)
    An attack using multiple sources (often a botnet) to flood a target with traffic, making it unavailable to legitimate users.
    DLL (Dynamic Link Library)
    A shared code module in Windows that multiple programs load and use. DLL hijacking places a malicious DLL where it is loaded instead of the legitimate one.
    DNS (Domain Name System)
    The internet's "phone book" — translates human-readable domain names (google.com) into IP addresses that computers use to communicate.
    DoS (Denial of Service)
    An attack from a single source that overwhelms a target system, making it unavailable to legitimate users.
    EDR (Endpoint Detection and Response)
    Security software that continuously monitors devices (endpoints) for suspicious behaviour, detecting attacks that traditional antivirus misses (including fileless malware and APTs).
    Encryption
    The process of transforming readable data (plaintext) into an unreadable format (ciphertext) using a mathematical algorithm. Only those with the correct key can decrypt it.
    Exploit
    A piece of code or technique that takes advantage of a vulnerability (a weakness in software, hardware, or configuration) to cause unintended behaviour.
    FIDO2 / Passkey
    A modern, phishing-resistant authentication standard. Authentication is cryptographically bound to the specific website domain — fake sites cannot trigger it. No password is ever transmitted.
    Firewall
    A security system that monitors and controls incoming and outgoing network traffic based on predefined security rules, creating a barrier between trusted and untrusted networks.
    Hash
    A one-way cryptographic transformation of data into a fixed-length string. Passwords are stored as hashes — the original password cannot be mathematically recovered from the hash alone.
    HTTP / HTTPS
    HTTP (HyperText Transfer Protocol) is the protocol for web communication. HTTPS is the encrypted version using TLS/SSL. Always look for HTTPS (the padlock) before entering sensitive information.
    IDOR (Insecure Direct Object Reference)
    A web vulnerability where an application exposes internal object identifiers (like database IDs) without verifying that the requesting user is authorised to access that specific object.
    IoT (Internet of Things)
    Network-connected physical devices beyond traditional computers: smart TVs, security cameras, routers, thermostats, industrial sensors. Often have weak default security configurations.
    IP Address
    A unique numerical label assigned to every device on a network, enabling communication between devices. Like a postal address for your computer.
    Keylogger
    Malware (or hardware) that records every keystroke typed, capturing passwords, credit card numbers, and private messages.
    Lateral Movement
    The technique used by attackers to progressively move through a network from the initial point of compromise towards high-value targets, using credentials and exploits along the way.
    Malware
    Malicious Software — any programme intentionally designed to damage, disrupt, steal from, or gain unauthorised access to a computer system.
    MFA (Multi-Factor Authentication)
    Authentication requiring two or more verification factors: something you know (password), something you have (phone/token), or something you are (fingerprint/face). Dramatically reduces account compromise risk.
    MitM (Man-in-the-Middle)
    An attack where the attacker secretly intercepts and possibly alters communications between two parties, with neither party aware of the interception.
    OSINT (Open Source Intelligence)
    Intelligence gathered from publicly available sources: social media, company websites, DNS records, news articles, and public databases. Used in reconnaissance.
    Passkey
    A passwordless authentication credential based on FIDO2 standards. Uses public-key cryptography tied to a specific domain, making phishing attacks impossible.
    Patch
    A software update that fixes known security vulnerabilities or bugs. Applying patches promptly is one of the most effective defences against cyberattacks.
    Payload
    The component of malware that actually causes damage or achieves the attacker's objective — e.g., the encryption module in ransomware or the data-stealing module in spyware.
    Phishing
    Deceptive communications (usually email) that impersonate trusted entities to trick recipients into revealing credentials, clicking malicious links, or installing malware.
    Privilege Escalation
    Gaining higher permissions than originally granted — typically from standard user to administrator/root — to achieve deeper system control.
    Ransomware
    Malware that encrypts a victim's files and demands payment (usually cryptocurrency) for the decryption key.
    Rootkit
    Malware designed to hide itself and other malicious software from the OS, antivirus, and administrators — typically by operating at kernel level.
    SIEM (Security Information and Event Management)
    A platform that collects, aggregates, and correlates log data from across an organisation's IT infrastructure to detect threats and support incident response.
    SMB (Server Message Block)
    A network file-sharing protocol used by Windows. Vulnerabilities in SMB (like EternalBlue) have been exploited by WannaCry and other worms.
    Social Engineering
    Psychological manipulation of people into performing actions or revealing confidential information, bypassing technical security controls by targeting human behaviour.
    Spear Phishing
    Targeted phishing aimed at a specific individual, using personalised information to increase credibility and success rate.
    SQL Injection (SQLi)
    Inserting malicious SQL code into an application input field to manipulate the backend database: extracting, modifying, or deleting data.
    SSL / TLS
    Cryptographic protocols that provide encrypted, authenticated communication over the internet. TLS is the modern successor to SSL. HTTPS uses TLS.
    Supply Chain Attack
    Compromising a trusted vendor, software provider, or hardware manufacturer to reach their customers — distributing malware through legitimate update channels.
    Trojan
    Malware disguised as legitimate, useful software. Relies on user deception to get installed rather than self-propagation.
    VPN (Virtual Private Network)
    Creates an encrypted tunnel for internet traffic, hiding content from network observers and masking the user's real IP address. Essential on public Wi-Fi.
    Vulnerability
    A weakness or flaw in software, hardware, or configuration that can be exploited by an attacker to compromise security.
    WAF (Web Application Firewall)
    A security layer that monitors, filters, and blocks HTTP traffic to and from a web application, protecting against SQLi, XSS, and other web attacks.
    WPA2 / WPA3
    Wi-Fi security protocols. WPA2 is the current standard but has known weaknesses. WPA3 is the newer, more secure successor with improved authentication and encryption.
    XSS (Cross-Site Scripting)
    Injecting malicious JavaScript into a web page that executes in other users' browsers, enabling session hijacking, credential theft, or page manipulation.
    Zero-Day
    A vulnerability that is unknown to the software vendor and therefore has no available patch. Extremely valuable to attackers because no defence exists until it's discovered and fixed.
    Zero Trust
    A security model based on "never trust, always verify." No user, device, or system is trusted by default — all access must be continuously authenticated and authorised.
