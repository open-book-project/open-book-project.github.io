    Tables of Transforms¶

    The pairs and properties used throughout the book, collected for reference

    Fourier series¶

    For \(x(t)\) with period \(T_0\) and \(\omega_0 = 2\pi/T_0\):

    \[ x(t) = \sum_{k=-\infty}^{\infty}a_ke^{jk\omega_0t}, \qquad a_k = \frac{1}{T_0}\int_{T_0}x(t)e^{-jk\omega_0t}\,dt . \]

    For \(x[n]\) with period \(N\):

    \[ x[n] = \sum_{k=\langle N\rangle}a_ke^{jk(2\pi/N)n}, \qquad a_k = \frac{1}{N}\sum_{n=\langle N\rangle}x[n]e^{-jk(2\pi/N)n} . \]
    Periodic signal Coefficients \(a_k\)
    \(e^{jM\omega_0t}\) \(1\) for \(k = M\), else \(0\)
    \(\cos M\omega_0t\) \(\tfrac12\) for \(k = \pm M\), else \(0\)
    \(\sin M\omega_0t\) \(\tfrac{1}{2j}\) for \(k = M\), \(-\tfrac{1}{2j}\) for \(k = -M\), else \(0\)
    \(\pm1\) square wave, \(+1\) on \((0, T_0/2)\) \(\dfrac{2}{j\pi k}\) for odd \(k\), \(0\) for even \(k\)
    pulse train, \(1\) for \(\lvert t\rvert < T_1\) \(\dfrac{\sin(k\omega_0T_1)}{\pi k}\); \(a_0 = \dfrac{2T_1}{T_0}\)
    triangle wave \(1 - 4\lvert t\rvert/T_0\) on \(\lvert t\rvert \le T_0/2\) \(\dfrac{4}{\pi^2k^2}\) for odd \(k\), \(0\) for even \(k\)
    impulse train \(\sum_n\delta(t - nT_0)\) \(\dfrac{1}{T_0}\) for all \(k\)

    Continuous-time Fourier transform¶

    \[ X(j\omega) = \int_{-\infty}^{\infty}x(t)e^{-j\omega t}\,dt, \qquad x(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty}X(j\omega)e^{j\omega t}\,d\omega . \]
    \(x(t)\) \(X(j\omega)\)
    \(\delta(t)\) \(1\)
    \(1\) \(2\pi\delta(\omega)\)
    \(u(t)\) \(\dfrac{1}{j\omega} + \pi\delta(\omega)\)
    \(e^{-at}u(t)\), \(a > 0\) \(\dfrac{1}{a + j\omega}\)
    \(te^{-at}u(t)\), \(a > 0\) \(\dfrac{1}{(a + j\omega)^2}\)
    \(e^{-a\lvert t\rvert}\), \(a > 0\) \(\dfrac{2a}{a^2 + \omega^2}\)
    \(\mathrm{rect}(t/\tau)\) \(\tau\,\mathrm{sinc}(\omega\tau/2\pi)\)
    \(\dfrac{\sin Wt}{\pi t}\) \(1\) for \(\lvert\omega\rvert < W\), else \(0\)
    \(e^{j\omega_0t}\) \(2\pi\delta(\omega - \omega_0)\)
    \(\cos\omega_0t\) \(\pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]\)
    \(e^{-t^2/(2\sigma^2)}\) \(\sigma\sqrt{2\pi}\,e^{-\sigma^2\omega^2/2}\)
    \(\sum_n\delta(t - nT)\) \(\dfrac{2\pi}{T}\sum_k\delta(\omega - 2\pi k/T)\)

    Table T.2. Continuous-time Fourier transform pairs.

    Property Signal Transform
    Time shift \(x(t - t_0)\) \(e^{-j\omega t_0}X(j\omega)\)
    Frequency shift \(e^{j\omega_0t}x(t)\) \(X(j(\omega - \omega_0))\)
    Scaling \(x(at)\) \(\frac{1}{\lvert a\rvert}X(j\omega/a)\)
    Differentiation \(dx/dt\) \(j\omega X(j\omega)\)
    Convolution \(x * y\) \(X(j\omega)Y(j\omega)\)
    Multiplication \(xy\) \(\frac{1}{2\pi}X * Y\)
    Parseval \(\int\lvert x\rvert^2dt\) \(\frac{1}{2\pi}\int\lvert X\rvert^2d\omega\)

    Table T.3. Main properties of the continuous-time Fourier transform (full list in Table 6.2).

    Discrete-time Fourier transform¶

    \[ X(e^{j\Omega}) = \sum_{n=-\infty}^{\infty}x[n]e^{-j\Omega n}, \qquad x[n] = \frac{1}{2\pi}\int_{2\pi}X(e^{j\Omega})e^{j\Omega n}\,d\Omega . \]
    \(x[n]\) \(X(e^{j\Omega})\)
    \(\delta[n - n_0]\) \(e^{-j\Omega n_0}\)
    \(a^nu[n]\), \(\lvert a\rvert < 1\) \(\dfrac{1}{1 - ae^{-j\Omega}}\)
    \(a^{\lvert n\rvert}\), \(\lvert a\rvert < 1\) \(\dfrac{1 - a^2}{1 - 2a\cos\Omega + a^2}\)
    \(1\) for \(0 \le n \le N - 1\) \(e^{-j\Omega(N-1)/2}\dfrac{\sin(\Omega N/2)}{\sin(\Omega/2)}\)
    \(\dfrac{\sin Wn}{\pi n}\), \(0 < W < \pi\) \(1\) for \(\lvert\Omega\rvert < W\), \(0\) for \(W < \lvert\Omega\rvert \le \pi\)
    \(e^{j\Omega_0n}\) \(2\pi\sum_k\delta(\Omega - \Omega_0 - 2\pi k)\)

    Table T.4. DTFT pairs (each transform is periodic with period 2π).

    Discrete Fourier transform¶

    \[ X[k] = \sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N}, \qquad x[n] = \frac{1}{N}\sum_{k=0}^{N-1}X[k]e^{j2\pi kn/N} . \]

    Bin \(k\) is at frequency \(kf_s/N\) (negative frequency \((k - N)f_s/N\) for \(k > N/2\)). Shifts and convolution are circular; for a real sequence \(X[N - k] = X^*[k]\); Parseval: \(\sum|x[n]|^2 = \frac1N\sum|X[k]|^2\).

    Laplace transform¶

    \[ X(s) = \int_{-\infty}^{\infty}x(t)e^{-st}\,dt . \]
    \(x(t)\) \(X(s)\) ROC
    \(\delta(t)\) \(1\) all \(s\)
    \(u(t)\) \(1/s\) \(\mathrm{Re}\{s\} > 0\)
    \(t^nu(t)/n!\) \(1/s^{n+1}\) \(\mathrm{Re}\{s\} > 0\)
    \(e^{-at}u(t)\) \(1/(s + a)\) \(\mathrm{Re}\{s\} > -a\)
    \(-e^{-at}u(-t)\) \(1/(s + a)\) \(\mathrm{Re}\{s\} < -a\)
    \(t^ne^{-at}u(t)/n!\) \(1/(s + a)^{n+1}\) \(\mathrm{Re}\{s\} > -a\)
    \(\cos(\omega_0t)u(t)\) \(s/(s^2 + \omega_0^2)\) \(\mathrm{Re}\{s\} > 0\)
    \(\sin(\omega_0t)u(t)\) \(\omega_0/(s^2 + \omega_0^2)\) \(\mathrm{Re}\{s\} > 0\)
    \(e^{-at}\cos(\omega_0t)u(t)\) \((s + a)/((s + a)^2 + \omega_0^2)\) \(\mathrm{Re}\{s\} > -a\)
    \(e^{-at}\sin(\omega_0t)u(t)\) \(\omega_0/((s + a)^2 + \omega_0^2)\) \(\mathrm{Re}\{s\} > -a\)

    Table T.5. Laplace transform pairs.

    Property Signal Transform
    Time shift \(x(t - t_0)\) \(e^{-st_0}X(s)\)
    Shift in \(s\) \(e^{s_0t}x(t)\) \(X(s - s_0)\)
    Differentiation (bilateral) \(dx/dt\) \(sX(s)\)
    Differentiation (unilateral) \(dx/dt\) \(sX(s) - x(0^-)\)
    Second derivative (unilateral) \(d^2x/dt^2\) \(s^2X(s) - sx(0^-) - x'(0^-)\)
    Integration \(\int_{-\infty}^{t}x\,d\tau\) \(X(s)/s\)
    Convolution \(x * y\) \(X(s)Y(s)\)
    Initial value \(x(0^+)\) \(\lim_{s\to\infty}sX(s)\)
    Final value \(x(\infty)\) \(\lim_{s\to0}sX(s)\) (poles of \(sX\) in the open left half-plane)

    Table T.6. Laplace transform properties.

    z-transform¶

    \[ X(z) = \sum_{n=-\infty}^{\infty}x[n]z^{-n} . \]
    \(x[n]\) \(X(z)\) ROC
    \(\delta[n]\) \(1\) all \(z\)
    \(u[n]\) \(1/(1 - z^{-1})\) \(\lvert z\rvert > 1\)
    \(a^nu[n]\) \(1/(1 - az^{-1})\) \(\lvert z\rvert > \lvert a\rvert\)
    \(-a^nu[-n-1]\) \(1/(1 - az^{-1})\) \(\lvert z\rvert < \lvert a\rvert\)
    \(na^nu[n]\) \(az^{-1}/(1 - az^{-1})^2\) \(\lvert z\rvert > \lvert a\rvert\)
    \(r^n\cos(\Omega_0n)u[n]\) \(\dfrac{1 - r\cos\Omega_0z^{-1}}{1 - 2r\cos\Omega_0z^{-1} + r^2z^{-2}}\) \(\lvert z\rvert > r\)
    \(r^n\sin(\Omega_0n)u[n]\) \(\dfrac{r\sin\Omega_0z^{-1}}{1 - 2r\cos\Omega_0z^{-1} + r^2z^{-2}}\) \(\lvert z\rvert > r\)

    Table T.7. z-transform pairs.

    Property Sequence Transform
    Time shift \(x[n - n_0]\) \(z^{-n_0}X(z)\)
    Unilateral shift \(x[n - 1]\) \(z^{-1}X(z) + x[-1]\)
    Scaling \(a^nx[n]\) \(X(z/a)\)
    Differentiation \(nx[n]\) \(-z\,dX/dz\)
    Convolution \(x * y\) \(X(z)Y(z)\)
    Initial value (\(x\) causal) \(x[0]\) \(\lim_{z\to\infty}X(z)\)
    Final value (\(x\) causal) \(x[\infty]\) \(\lim_{z\to1}(1 - z^{-1})X(z)\)

    Table T.8. z-transform properties.
